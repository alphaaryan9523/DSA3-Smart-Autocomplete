    How it works

    01

    Build the Trie

    Every dictionary word is inserted character by character; terminal nodes retain a frequency score.

    02

    Search prefixes

    The query walks one path of length m, then DFS collects and ranks completions below that node.

    03

    Repair typos

    If no prefix matches, Levenshtein DP measures insertions, deletions and substitutions to suggest nearby words.
